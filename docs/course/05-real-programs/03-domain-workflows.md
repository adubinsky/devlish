# Lesson 5.3: Domain Workflows

Last updated: 2026-03-23
Status: Current lesson.

## Purpose

Show that the same programming ideas can be applied to different kinds of
real-world work.

## Learning Goals

- recognize shared logic across different domains
- explain how one workflow pattern can solve many business problems

## Vocabulary

- domain
- workflow
- rule
- process

## Big Idea

The domain changes, but the programming pattern often stays the same:
- store values
- compare them
- decide what to do next
- produce a result

That is why learning programming ideas is more powerful than memorizing one
specific example.

## Practice

1. Read all three examples.
2. Identify the decision point in each one.
3. Describe one new workflow from your own domain.
