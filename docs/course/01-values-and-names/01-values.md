# Lesson 1.1: Values

Last updated: 2026-03-23
Status: Current lesson.

## Purpose

Introduce the idea that programs work with pieces of information called
values.

## Learning Goals

- recognize strings, numbers, and true-or-false values
- explain that a value is information the program can use

## Vocabulary

- value
- text
- number
- true
- false

## First Example

```text
invoice_amount equals 1200
review_needed equals false
decision_label equals "approved"
```

Open the example file here:
- [01_values.dvl](/Users/admin/code/devlish/docs/course/01-values-and-names/examples/01_values.dvl#L1)

## Big Idea

A value is a piece of information.

In this example:
- `1200` is a number
- `false` is a true-or-false value
- `"approved"` is a piece of text

## Run It

```bash
./bin/devlish run docs/course/01-values-and-names/examples/01_values.dvl --debug
```

## Line By Line

### `invoice_amount equals 1200`

This stores a number.

### `review_needed equals false`

This stores a true-or-false value.

### `decision_label equals "approved"`

This stores text.

## Practice

1. Which line uses a number?
2. Which line uses text?
3. Which line uses a true-or-false value?
4. Change `false` to `true` and run the file again.
